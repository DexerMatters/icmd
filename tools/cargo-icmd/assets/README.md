# Bundled raster asset

`guide.png` is the documentation guide's own sample image. It exists so the
raster chapter can show real decoding, fitting, alignment, and render-mode
behavior without touching the network, a user path, or an external package.

- **Source:** original work authored for this repository and generated by
  `generate.py` in this directory.
- **License:** MIT OR Apache-2.0, matching the rest of the repository.
- **Size:** 144 x 96 RGB, under 2 KiB, so it fits comfortably inside the default
  image budget.
- **Reproduce:** `python3 tools/cargo-icmd/assets/generate.py`.

The image is decoded once at runtime with `RasterImage::decode`, and the
generated `Symbols` mode is deterministic enough for automated tests.
